# SkillMock AI

Resume-grounded mock interviewer. Upload a resume, get an ATS report, then
answer technical questions generated from your own projects and see how specific
your answers actually sound.

Source: https://github.com/shrutz2/SkillMock

Set `GROQ_API_KEY` in this Space's settings to enable real question generation.
Without a key the app runs with an offline mock provider.
